Installation
1
Install from CRAN 
install.packages("Rhobots")
2
Install the torch backend (once per machine, ~560 MB) 
library(Rhobots)
rhobots_install()   # restart R when prompted
3
Try the built-in demo 
rhobots_demo()   # downloads Gutenberg books, fits a model, opens a plot

2.2: Explain an R script

You are provided with the following R script that aims to compute the fibonacci sequence. Explain each line of code in this script. Provide the output of the script. Note: you are not requested to explain how the sequence is computed (i.e explain why we store values, why they are added, what a sequence is), only what a line of code does.

generate_fibonacci <- function(limit) {
  fib_sequence <- c(0, 1)
  prev <- fib_sequence[1]
  curr <- fib_sequence[2]
  next_value <- prev + curr
  while (next_value <= limit) {
    fib_sequence <- c(fib_sequence, next_value)
    prev <- curr
    curr <- next_value
    next_value <- prev + curr
  }
  return(fib_sequence)
}
fib_seq <- generate_fibonacci(3)
print(fib_seq)
